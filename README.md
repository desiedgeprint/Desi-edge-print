# Desi Edge Print Website

## Files
- `index.html` — main website
- `style.css` — design/CSS
- `script.js` — website behavior
- `products.js` — **edit this one file to add/change products**
- `image01.jpg` ... `image10.jpg` — product images

## Add a new product later
1. Upload the new image to the GitHub repository root (for example `image11.jpg`).
2. Open `products.js` and copy one product line.
3. Change the name, price, description, and image filename.
4. Click **Commit changes**.
5. GitHub Pages will publish the update automatically.

Keep `index.html`, `style.css`, and `script.js` unchanged unless you want to change the website layout/functionality.
